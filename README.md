# ☠️ Algorithm Apocalypse

**Survive the chaos. Conquer the algorithms!**

Algorithm Apocalypse is an interactive console-based game developed using C programming. It combines Data Structures and Algorithms with gaming elements to make algorithm learning more engaging and challenging.

## 🎯 Objectives
- Apply DSA concepts through practical challenges.
- Improve logical thinking and problem-solving skills.
- Learn algorithms through interactive gameplay.

## 🛠️ Technologies
- C Programming
- Data Structures and Algorithms

## 🎮 Features
- Interactive gameplay
- Multiple algorithm-based challenges
- Player scoring system
- Lives and rewards
- Level-based progression

## ⚙️ How to Run

Compile using GCC:

```bash
gcc main.c -o apocalypse
```

Run on Windows:

```bash
apocalypse.exe
```

## 📚 Concepts

The project explores sorting, searching and other fundamental Data Structures and Algorithms concepts.
